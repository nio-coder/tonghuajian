# 同话间 Android 品牌图标实测

<img src="tonghuajian.png" width="112" height="112" alt="同话间双对话框应用图标">

用一张 512 × 512 的同话间标志图，运行产品 Android 工程的图标生成任务。任务完成后逐个读取生成文件，核对 PNG 格式、像素尺寸和文件摘要。可以下载样包并与下面的规格对照。

| Android 资源目录 | 生成尺寸 |
|---|---|
| mipmap-mdpi | 48 × 48 |
| mipmap-hdpi | 72 × 72 |
| mipmap-xhdpi | 96 × 96 |
| mipmap-xxhdpi | 144 × 144 |
| mipmap-xxxhdpi | 192 × 192 |

[下载五档资源和校验清单](https://github.com/nio-coder/tonghuajian/releases/download/android-brand-v1/android-brand-resources.zip)

这次实测覆盖 Android 图标生成环节。安装包签名、终端展示、消息服务和 iOS 品牌配置需分别验收。采购方可用同一张自有素材提出试点需求，并在约定的设备上核对最终图标。
